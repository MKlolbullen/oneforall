Workspaces

The engagement / customer / asset boundary. Workspace cards show targets / runs / findings / loot counts and link into the rest of the app filtered to that workspace. The topbar selector is the single source of truth.
How these were built. Each page is a static HTML file under apps/web/preview/. They share the sidebar / topbar via _chrome.js and the visual primitives via _shared.css — so the sidebar grouping, badges, cards, tables and severity colours stay in sync across pages. None of these files are part of the Vite build; open them directly with file:// or serve the directory with any static file server.
