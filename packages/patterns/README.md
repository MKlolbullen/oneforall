# Pattern Packs

`sniper-grep-patterns.yaml` contains Sn1per-style regex categories for finding interesting subdomains, extensions and parameters during URL/JS/artifact analysis.

Categories include XSS, SSRF, open redirect, RCE, IDOR, SQLi, LFI, SSTI, debug/admin and high-value parameters.

API endpoint:

```text
GET /api/config/grep-patterns
```
